## 1. Executive Summary (What Is Done)

1. **Selected & Scoped Capstone Direction:**
   - **Project #1 — PuppyPi Teach & Find** (*Active Object Search Using Few-Shot Visual Memory and Topological Navigation*) tailored to **Hiwonder PuppyPi Standard** (8-DOF servos, single 640×480 RGB nose camera, AprilTags, no LiDAR).
2. **Hiwonder `ros2` Source Code Audited (`Hiwonder/PuppyPi`):**
   - Identified and worked around 4 real driver traps:
     - `/puppy_control/velocity` drops lateral motion when `y != 0` $\rightarrow$ routed lateral arcs to `/puppy_control/velocity_move`.
     - `/puppy_control/pose` drops poses when `yaw != 0` $\rightarrow$ locked `Pose.yaw = 0.0` and used `yaw_rate` body turns.
     - Stock `apriltag_tracking_demo.py` blocks camera callbacks with `time.sleep(1)` and uses `3.3 cm` tags $\rightarrow$ implemented non-blocking frame buffering + `10 cm` `tag36h11` markers (`IPPE_SQUARE`).
3. **Complete Pure-Python Core Built (`teach_and_find/`):**
   - `apriltag_pose.py`: OpenCV `DICT_APRILTAG_36h11` + `SOLVEPNP_IPPE_SQUARE` 6-DOF pose estimator & printable tag generator.
   - `perception/`: `CandidateProposalGenerator` (LAB chrominance + HSV saturation foreground proposer), `SpatialAppearanceEncoder` & `TorchHubBackboneEncoder` (DINOv2-ready), `ObjectMemoryBank` (multi-angle prototypes, distractor margin, Dirichlet station priors).
   - `verification.py`: IEVE-inspired sequential Bayesian log-odds multi-view verifier (`0°`, `±60°` lateral arcs).
   - `planner.py`: Topological graph (`HOME`, `Station_A/B/C`) + `ActiveSearchPlanner` ($S(z)=\alpha P(z)-\beta\tilde{D}(z)+\gamma U(z)$) + `SequentialSearchPlanner` baseline.
   - `mission.py`: `FailureAwareMissionController` FSM with `RECOVER_TAG` recovery and safe return-to-`HOME`.
   - `ros2_bridge.py` & `edge_client.py` + `scripts/puppypi_edge_relay.py`: Portable Sim-to-Real hardware bridge (both Onboard `rclpy` node and Zero-Dependency Offboard TCP Relay with `0.30 s` safety watchdog).
4. **Closed-Loop 3D Benchmarks & MuJoCo CAD Visualization Completed:**
   - **4-Way Ablation (`160` episodes = `40` randomized trials × `4` variants):**
     - `V0` Baseline (Sequential + 1-View): **`25.0%`** true success, **`75.0%`** false verification.
     - `V3` Full System (Active `S(z)` + Multi-View): **`100.0%`** true success, **`0.0%`** false verification, **`-31.9%`** stations inspected (`2.38 → 1.62`), **`-22.0%`** walking distance (`7.53 m → 5.87 m`).
   - **3D MuJoCo Arena (`mujoco_arena.py`):** Built with official Hiwonder PuppyPi Standard 8-DOF STL CAD meshes (`assets/puppypi_description/meshes/`) and GPU headless EGL rendering (`MUJOCO_GL=egl`).
